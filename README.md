# Python Data Processing and Analysis Assignment

This repository contains solutions to six real-world data processing problems using Python. The assignment focuses on applying core Python data structures like **dictionaries, lists, tuples, and strings** to solve practical scenarios.

## 🚀 Problem Statements

### 1. Employee Performance Bonus Eligibility
Identifies top-performing employees by finding the highest score and handling ties.
* **Key Concept:** Dictionary value extraction and list comprehension.

### 2. Search Query Keyword Analysis
Analyzes search query frequency, filtering for keywords used more than once.
* **Key Concept:** String manipulation (`.lower()`, `.split()`) and frequency mapping.

### 3. Sensor Data Validation
Filters "even-numbered" readings from a list of sensor data and pairs them with their timestamp (hour).
* **Key Concept:** Data filtering and the `enumerate()` function.

### 4. Email Domain Usage Analysis
Calculates the distribution percentage of different email providers within a user base.
* **Key Concept:** Substring extraction and percentage calculation.

### 5. Sales Spike Detection
Calculates average daily sales and flags days where sales exceed a specific threshold (30% above average).
* **Key Concept:** Arithmetic mean calculation and conditional flagging.

### 6. Duplicate User ID Detection
Scans a registration list to identify and count duplicate User IDs to ensure data integrity.
* **Key Concept:** Frequency counting and dictionary iteration.
